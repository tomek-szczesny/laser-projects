# rozen-box

Laser-cut case for my PC, based on a laptop motherboard (SVG/Boxes.py-based design).

- `parts/sources/` — master/source SVG (`rozen_box.svg`)
- `parts/` — exported/design SVG variants
- `docs/` — reference sketches (components/PCB)
- `process.sh` — SVG-to-G-code post-processing script using the [la suite](https://github.com/tomek-szczesny/la)
