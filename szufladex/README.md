# szufladex

Laser-cut modular storage/drawer system (SVG/Boxes.py-based design).

This project was converted to a Git repository at version **v2.2**.

This repository preserves the design files and processing script in a cleaned-up layout:
- `parts/` — part/export design files (SVG and G-code)
- `parts/sources/` — master/source SVG inputs
- `process.sh` — G-code post-processing script using the [la suite](https://github.com/tomek-szczesny/la)
- `dimensions` — dimension and sheet-layout notes
- `notes` — design notes

## Legacy status of `dimensions` and `notes`

`dimensions` and `notes` are kept for **historical/reference purposes**. They may not be fully accurate or up to date (for example, some divider options/sheet-layout details may be tentative or reflect earlier planning). Verify against the actual design files before relying on them.
