# nakladex

Parametric generator of laser-cut cases for clip-on sunglasses (and other flat things).

## Contents

- `nakladex.c` — C (Cairo) generator producing SVG variants (e.g. front/back/spacer) based on width/length parameters
- `makefile` — builds and runs the generator, then processes SVG outputs
- `process.sh` — SVG-to-G-code post-processing pipeline using `la` tools
- `LICENSE`
