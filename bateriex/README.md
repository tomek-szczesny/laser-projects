# bateriex

Parametric generator for a laser-cut battery organizer/holder board.

## Contents

- `bateriex.c` — C (Cairo) generator producing SVG parts for the organizer (including riser/support parts)
- `makefile` — builds and runs the generator, then processes SVG outputs
- `process.sh` — SVG-to-G-code post-processing pipeline using `la` tools
- `LICENSE`
